## 6. Design Rationale
Document approximately three important decisions.

### Decision 1
**Problem:**
Wouldn't showing hike time on the trail cards.

**Design response:**
Shows hike time for each trail card, same goes with miles and distance than showing the numbers.

**Why:**  
So the time would show and Maya would be able to see what's 3 hours and less.

### Decision 2
**Problem:**
Explain difficulty levels on the cards.

**Design response:**
Got rid of the buttons that used to have "Easy", "Moderate", and the others, and put it with the cards, and added a search bar as well.

**Why:**
Maya would be able to figure out which one's are easy, that way she doesn't have to search for long.

### Decision 3
**Problem:**
Make important information easier to find.

**Design response:**
Added a section where it shares important information on what you need to bring before getting on a hike.

**Why:**
For safety reasons, and for beginners like Maya that learn on what they need for a hike.
