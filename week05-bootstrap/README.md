# Cedar & Stone Home Services — Week 5 Starter Project

## 1. Framework Choice

What I think one feature Bootstrap was more significantly faster to implement is the responsive grid. The container, column, and rows were more responsive layouts of different viewpoint widths without having to use the custom grid system.

## 2. Adaptation

One of the Bootstrap defaults that I intentionally changed for the client is default button and page styling to use the color palettes the cilent provided. I did it because it keeps the Bootstrap structure while using the prototype to match what the client wanted.

## 3. Professional Judgment

One part of the project that I would not rebuild from scratch is the responsive navigation because Bootstrap already has a appropriate solution of the responsive navbar. The reason why I kept it is because it saves time when making the website and settles a responsive and interactive behavior.
